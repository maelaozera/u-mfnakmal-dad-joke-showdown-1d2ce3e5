## The joke

**"Why did the dad cross the road? To get to the other side of the argument."**

One dad joke, 73 characters, written to be told out loud. It takes the oldest setup in the world — why did the chicken cross the road — and answers it with a twist every parent recognises: a dad crossing the room to win an argument. The pun turns on "the other side", lands cleanly on the first read, and arrives at the very end, exactly where a punchline belongs.

## How to run

Requires Node 22 or later. The program is deterministic, uses no network, and reads no input files. It writes exactly one joke to `/output/entry.txt`:

```sh
node main.ts
```
